# Intro to Backend Tutorial 🚀

This project is a beginner-friendly tutorial for learning backend development. It sets up a basic Node.js and Express server connected with a MongoDB database.

## ✨ Features
* **Express Server:** Configured and running smoothly on port `4000`.
* **Database Integration:** Secure connection established with **MongoDB**.
* **Clean Architecture:** Organized folder structure for configuration, source code, and environment setups.

## 🛠️ Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB
* **Version Control:** Git & GitHub

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   ```

2. **Navigate to the backend directory:**
   ```bash
   cd backend
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the server:**
   ```bash
   npm start
   ```
   *(Or `npm run dev` if you are using nodemon)*

*This repository is built for educational purposes to understand the basics of Node.js, Express, and Database connectivity.*
